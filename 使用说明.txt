职途 · 求职简历管理工具  v1.0.0
==================================================

【怎么开始】只有三步

  1. 确认电脑装了 Python 3（Win10/11 一般没有预装）
     - 打开 https://www.python.org/downloads/ 下载安装
     - 安装时务必勾选 "Add Python to PATH"

  2. 双击本文件夹里的 start.bat
     - 会弹出一个黑色命令行窗口，不要关它
     - 浏览器会自动打开工具页面，没自动打开就手动访问
       http://127.0.0.1:8765/

  3. 用完之后，关掉那个黑色窗口就是停止服务


【第一次用建议按这个顺序】

  我的简历  →  填基本信息、教育经历、实习/项目、技能
               （顶部会显示完整度，80% 以上就能投了）

  找工作    →  输入"后端实习""数据分析""产品经理"等关键词搜索
               每个岗位都会用你的简历算匹配度

  粘贴 JD 导入  →  BOSS 直聘、实习僧这些平台没有公开接口，
                   把岗位描述整段复制粘贴进来，工具会自动识别
                   岗位名称、公司、城市、薪资、截止时间和技能

  投递追踪  →  心动的岗位点"加入投递"，在看板里推进阶段
               填了"下一步行动 + 日期"，概览页会提醒你

  面试准备  →  42 道常见问题 + 答题思路，还能用 STAR 生成器
               把自己的经历写成能直接讲的答案


【数据存在哪里，会不会丢】

  所有数据都保存在这台电脑的浏览器里（localStorage），
  不会上传到任何服务器，换台电脑也看不到。

  所以：换电脑 / 换浏览器 / 清理浏览器数据之前，
  请先到「数据与设置」页面点"导出全部数据"备份成 JSON，
  新环境里再用"从备份导入"恢复。


【常见问题】

  Q: 提示"没有检测到 Python"
  A: 说明没装 Python 或者安装时没勾 "Add Python to PATH"。
     重新安装并勾选该选项，或者安装后在命令行执行 python --version
     确认能看到版本号。

  Q: 端口被占用 / 打开页面是空白的
  A: 黑色窗口里会显示实际访问地址（可能是 8766、8767），
     照着那个地址访问即可。

  Q: 岗位搜索搜不到中文公司
  A: 内置的在线数据源是 Remotive、Arbeitnow、Jobicy、RemoteOK，
     以海外和远程岗位为主。中文岗位请用"粘贴 JD 导入"保存进来，
     匹配度算法完全一样。

  Q: 断网了还能用吗
  A: 简历、投递追踪、面试准备都能正常用；岗位搜索会自动
     切换到内置的示例岗位库。
